# Shashank Ramesh Kumar — Portfolio

Source code for my software engineering portfolio, exported from [the original site](https://shashank-ramesh-kumar.srk181.chatgpt.site).

The portfolio presents my experience, technical skills, education, contact information, and downloadable résumé. It is a responsive static website built with HTML and CSS, with no build step or third-party dependencies.

## Run locally

With Python 3 installed, run this command from the repository root:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000> in your browser. Stop the server with `Ctrl+C`.

## Files

| Path | Purpose |
| --- | --- |
| `index.html` | Complete website markup and styles |
| `Shashank_Ramesh_Kumar_Resume.pdf` | Downloadable résumé |
| `.gitignore` | Local files and credentials excluded from version control |

## Edit or deploy

Edit `index.html` to update the page. Replace the résumé PDF using the same filename to keep the download link working. A static host should serve the repository root directly; no install or build command is needed.

The HTML and résumé PDF are unchanged from the original Sites source. This standalone export places them at the repository root and omits the hosting configuration specific to the original Sites project.
